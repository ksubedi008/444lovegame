# Requirements

## Functional Requirements

- User can log in
- User can click hearts
- Each heart shows unique message
- No message repetition
- User can play games
- Game rewards unlock messages
- User can send messages
- Admin can view and reply

---

## Non-Functional Requirements

- Responsive design
- Smooth animations
- Fast loading
- Secure login

---

## Message Requirements

Short Messages:
- 444 total
- 3–5 lines
- Poetic tone

Reward Messages:
- Ordered unlock
- Deeper emotional content

---

## Game Requirements

- 2–3 mini games
- Easy difficulty
- Reward after 3 wins

---

## UI Requirements

- Black + Purple theme
- Handwritten font
- Glow effects

---

## Audio Requirements

- Piano background music
- Click sound effects

---

## Admin Requirements

- Custom dashboard
- View progress
- Message system
