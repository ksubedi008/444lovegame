# User Flow

## 1. Home Page

- 444 floating hearts
- Hearts follow cursor slightly
- Background music starts on first interaction

User Actions:
- Click heart → show short message
- Heart disappears

---

## 2. Entry Point

Button:
"Enter if you dare..."

---

## 3. Intro Animation

Display:
"Happy birthday gudiyaaa, I love you the mostttt."

Then redirect to login

---

## 4. Login Screen

- Input username/password

Wrong attempt:
"You forgot already?"

Correct → Game Screen

---

## 5. Game Flow

- User plays mini-game
- After 3 wins → unlock reward message

Lose:
- Retry immediately

---

## 6. Reward Flow

- Show long emotional message
- May include:
  - Voice note
  - Image

---

## 7. Message Interaction

- User can send reply
- Admin can respond later

---

## 8. Progression

- Hearts unlock short messages
- Games unlock deep messages
- Everything builds emotional story

---

## 9. Ending

- After all rewards unlocked:
  - Final message
  - Emotional reveal
  - Purple theme significance
